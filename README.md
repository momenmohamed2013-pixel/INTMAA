# نظام انتماء - إدارة المهام والأداء KPI

نظام كامل لإدارة مهام وأداء المهندسين في مكتب الاستشارات الهندسية.

**تصميم: م. مؤمن رمضان**

---

## 🚀 التشغيل السريع

### 1. المتطلبات
- Node.js 18+
- PostgreSQL 14+

### 2. إعداد قاعدة البيانات

```bash
# إنشاء قاعدة البيانات في PostgreSQL
createdb intima_db
```

### 3. إعداد المشروع

```bash
# نسخ ملف البيئة
cp .env.example .env

# تعديل .env بإضافة بيانات الاتصال
# DATABASE_URL="postgresql://USERNAME:PASSWORD@localhost:5432/intima_db"

# تثبيت الحزم
npm install

# رفع الـ schema إلى قاعدة البيانات
npm run db:push

# إضافة البيانات التجريبية
npm run db:seed

# تشغيل المشروع
npm run dev
```

### 4. فتح المتصفح
http://localhost:3000

## 🧮 معادلة KPI

```
KPI = (نسبة الإنجاز × 40%) + (الالتزام بالوقت × 40%) + (الجودة × 20%)
```

- **نسبة الإنجاز**: المهام المكتملة / الإجمالي × 100
- **الالتزام بالوقت**: مع خصم تدريجي 2% لكل يوم تأخير (حد أقصى 100%)
- **الجودة**: 80% افتراضي، يمكن تعديله عند إدخال المهمة

## 🔧 أوامر مفيدة

```bash
npm run db:studio    # فتح Prisma Studio لعرض قاعدة البيانات
npm run db:push      # تحديث قاعدة البيانات بعد تعديل schema
npm run db:seed      # إعادة تعبئة البيانات التجريبية
npm run build        # بناء للإنتاج
```
